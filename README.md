# مزرعتي الذكية — نموذج أولي

## ما الذي يعمل الآن؟
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر.
- تسجيل وتعديل وحذف مجموعات الحيوانات والطيور.
- سجل الصحة والأدوية والتحصينات ومواعيد المتابعة.
- تسجيل حركات الأعلاف والمخزون.
- سجل المبيعات والمشتريات والإيرادات والمصروفات والديون.
- الإنتاج والتكاثر والمواليد والبيض والفقس والحليب والأوزان والنفوق.
- إضافة أنواع جديدة.
- حفظ تلقائي محلي في المتصفح، بحث داخل السجلات، تصدير واستعادة نسخة JSON.

## تشغيل النموذج محليًا
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو Edge أو Firefox.
3. ابدأ من «الحيوانات والطيور» وأضف أول مجموعة.
4. من وقت لآخر اضغط «نسخة احتياطية» واحفظ ملف JSON في مكان آمن.
5. لاستعادة البيانات في هذا المتصفح اضغط «استعادة» واختر ملف النسخة.

**مهم:** النسخة الحالية تحفظ البيانات في المتصفح والجهاز الحالي فقط. لا تمسح بيانات المتصفح قبل تصدير نسخة احتياطية. لا توجد مزامنة سحابية فعلية أو حسابات مستخدمين في هذه النسخة.

## قاعدة البيانات والمزامنة عبر الإنترنت
الملف `schema.sql` هو نقطة بداية لمخطط قاعدة بيانات Supabase مع Row Level Security. لربط الأجهزة فعليًا، يلزم:
1. إنشاء مشروع Supabase وتفعيل تسجيل الدخول.
2. تشغيل `schema.sql` في SQL Editor.
3. إضافة عميل Supabase إلى الواجهة، مع استخدام المفتاح العام فقط، وعدم تضمين `service_role`.
4. تنفيذ طبقة مزامنة مع معالجة التعارضات، وربط كل سجل بمستخدم ومزرعة.
5. اختبار سياسات الوصول والنسخ الاحتياطي والاستعادة قبل إدخال بيانات حقيقية.

لا يحتوي النموذج على أسرار أو مفاتيح سحابية. لم تُفعّل المزامنة السحابية لأن ذلك يتطلب مشروعًا سحابيًا ومفاتيح إعداد يملكها المستخدم.

## ملاحظات السلامة
- جدول الأدوية هنا لتسجيل وصفات ومواعيد يحددها الطبيب البيطري؛ لا يوصي بجرعات أو بروتوكولات علاجية.
- الأرقام المالية لا تشمل ضرائب أو محاسبة قانونية.
- قبل الاستخدام التجاري، أضف صلاحيات المستخدمين، وسجل تدقيق، واختبارات واستراتيجية نسخ احتياطي سحابية.
